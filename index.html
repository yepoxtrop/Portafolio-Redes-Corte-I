Redes de Computadores // Portafolio de Ingeniería

Este portafolio tiene como objetivo documentar nuestro proceso y avance en la asignatura de Redes de Computadores, integrando tanto los conocimientos teóricos como las experiencias prácticas adquiridas durante el curso.

Dentro de este espacio encontrará apuntes, actividades y ejercicios prácticos que abarcan temas como el diseño y configuración de redes, el análisis de protocolos de comunicación y la implementación de soluciones tecnológicas. Cada sección busca evidenciar el aprendizaje obtenido y demostrar nuestra capacidad para aplicar los conceptos en escenarios académicos y profesionales.

Además de ello podrá acceder al código fuente de este website y adicional a ello descargalo como un PDF.
